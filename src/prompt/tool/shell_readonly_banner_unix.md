- Writes outside the temp root are refused: redirects, in-place editors (`sed -i`, `awk -i inplace`), `dd of=`, file and tree mutators, and package managers. `/dev/null` is allowed; `$TMPDIR` is the temp root. A command word must be literal or bound to a literal in the same line; `sh -c …` is not chased; names match case-sensitively.
