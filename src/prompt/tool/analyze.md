Dispatch one round of parallel analysts to research a question or investigate part of the workspace. Analysts are read-only: they explore, compare options, and report structured claim-level findings (three decorrelated analysts run in parallel, then their findings are consolidated with agreement brackets and contradictions). They cannot edit files.

Use `analyze` for quick clarification, a focused question, or a bounded investigation that a single round of analysis can answer directly. For deep, broad, multi-faceted questions use `research` instead. The `analyze` parameter contains the question the analysts should work on. Execution mode depends on the caller: the Manager and Assistant dispatch asynchronously (results arrive later via a notification) while the Engineer and Maintainer wait synchronously and receive the result immediately.
