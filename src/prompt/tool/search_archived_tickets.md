Search the archive of completed/cancelled tickets across the whole installation — every workspace — by title. Uses hybrid search (keyword + semantic similarity). Returns up to 10 best matches, each formatted as `[workspace] [phase] id: title` so a hit can be opened wherever it was filed. Use `get_ticket` with the returned IDs to inspect a matching ticket — by default a truncated view (header metadata in full, description capped at 500 chars, all but the three newest comments capped at 200 chars), or the complete un-truncated ticket with `full: true`. Often works better using multiple parallel invocations with differently worded queries.
