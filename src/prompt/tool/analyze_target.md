You can point this round at another directory: pass `target` with either the exact name of a registered workspace (case-sensitive) or an absolute path to a directory. The analysts then read and search that directory, with that directory's own context, and their findings are about it. An absolute path that is a registered workspace is treated as that workspace. The filesystem root is refused. Leave `target` out to run in your own workspace as before; a target applies to this call only, and the result names the directory that was really used.
