Read one ticket by `ticket_id` (a bare number or `<workspace>-<number>`; a prefixed ID from any workspace is accepted, so an archive hit opens wherever it was filed).

By default a ticket you created comes back truncated: full header, a shortened description and short comments except the newest few. `full: true` returns everything; a ticket another agent created is always returned in full. Use it to review a ticket's history, analyst findings, verification results and user notes before acting.
