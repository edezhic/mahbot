Retrieve the details of a ticket by its `ticket_id`. By default the response shows the ticket's header metadata (id, title, phase, priority, reporter, workspace, created/updated dates, supersedes / superseded-by / prerequisites links, and the archived flag) in full, truncates the description to 500 characters (appending `…` when it exceeds that), and truncates every comment's content to 200 characters except the three newest comments, which are shown in full. Pass `full: true` to get the complete un-truncated ticket (full description and the complete comment thread). The default truncated view applies only when the ticket was created by you (same creator); tickets created by another agent are always returned in full. Comments contain analyst findings, reviewer notes, QA results, and messages from the user or manager. Use this tool when you need to review a ticket's history, check what reviewers or analysts have already found, or understand the current state of a ticket before taking action on it. The `ticket_id` may be a bare number (e.g. `123`) or the fully prefixed form (e.g. `workspace-123`); only tickets from the current workspace are accessible.
