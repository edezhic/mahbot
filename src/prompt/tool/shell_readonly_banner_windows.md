- Writes outside the temp root are refused: redirects, file and tree mutators (with `copy`/`xcopy`/`robocopy` gated on destination), and the named package managers. `NUL` is allowed; `%TMP%`/`%TEMP%` mean the same daemon temp root. Double-quote a temp path with a space, name write targets absolutely, keep a caret or `!NAME!` out of an operand, and space a switch from its operand. `set TEMP=…` is refused.
- Shapes the guard's parser cannot read (`if exist x ( … )`, `for` loops) stay refused; a command word spelled through a variable, a caret or a trailing dot passes. `PATHEXT` and `ComSpec` decide the interpreter; `HOME`/`%TMP%`/`%TEMP%` are the values the product pins.
