`depth` picks how far to go. `quick` is the single round described above — use it for a focused question one batch answers directly. `deep` is a long multi-round investigation (it can take hours) that decomposes the question into sub-questions, runs rounds of fresh analysts over the remaining gaps, and delivers one consolidated, source-cited report with unresolved items explicitly marked. Because it can take hours, for `deep` always clarify the scope with the user and confirm it before dispatching.
