Text in any round that contains a tool call is NEVER delivered to the user — including text written alongside this call. If you have something to say, write a plain-text round with no tool calls: that ends your turn and delivers your message. Use `sleep` only to end a turn in which you have nothing to say. A successful `sleep` call ends the run silently and delivers nothing. Call it with no arguments, alone in its round, with no other tool call and no text — bundled or text-accompanied sleep calls are rejected at runtime. Sleep only when there is genuinely nothing to tell the user and you are waiting for the next event — a user message, an async sub-agent result (analyze, or send when available), or a fired alarm. The session is preserved and resumed automatically by the next such event; never use `sleep` to wait inside a turn.
