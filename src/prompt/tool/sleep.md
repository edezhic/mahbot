Text in any round that contains a tool call is NEVER delivered to the user — including text written alongside this call. If you have something to say to the user, write it as a plain-text round with no tool calls at all: that ends your turn and delivers your message. Use `sleep` only to end a turn in which you have nothing to say to the user. A successful `sleep` call ends the run silently and delivers nothing. Call it with no arguments, alone in its round, with no other tool call and no text — bundled or text-accompanied sleep calls are rejected at runtime. Sleep only when there is genuinely nothing to tell the user right now and you are waiting for the next event — a user message, the result of an async sub-agent run (analyze, or implement/research when available), or a fired alarm. The session is preserved and will be resumed automatically by the next such event; never use `sleep` to wait inside a turn.
