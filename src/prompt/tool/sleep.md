End the run silently: a successful `sleep` call finishes the turn and nothing is delivered to the user — no reply is sent. Call it alone, with no arguments, never bundled with other tool calls. A round containing any tool call is never delivered, so text written in the same round as `sleep` is NOT delivered to the user — if there is something the user should hear, send it as a plain text round with no tool calls instead of sleeping. Sleep only when there is genuinely nothing to tell the user right now and you are waiting for the next event — a user message, the result of an async sub-agent run (analyze, or implement/research when available), or a fired alarm. The session is preserved and will be resumed automatically by the next such event; never use `sleep` to wait inside a turn.
