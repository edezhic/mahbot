Path restrictions: paths must be within the workspace or within common dependency source directories; absolute paths are allowed for temp files (spill files under `$TMPDIR` on unix, `%TMP%`/`%TEMP%` on Windows) and dependency sources. Reachable caches include Rust (`~/.cargo/registry/src/`, `~/.cargo/git/checkouts/`, `~/.rustup/toolchains/`), Python (`~/.local/lib/`, `/usr/local/lib/`, `/usr/lib/`, conda/poetry/pipenv/uv/rye), Java (`~/.m2/repository/`, `~/.gradle/caches/`), JavaScript (bun, pnpm, npm, `~/.npm`, nvm/volta/yarn), Go (`~/go/pkg/mod/`, `$GOROOT/src`), Ruby, PHP, C/C++, Swift, Dart, Elixir, Haskell, Lua, R, OCaml, Julia, Nix (`/nix/store/`, read-only) and system roots. Relocated roots are honoured through `CARGO_HOME`, `RUSTUP_HOME`, `GOMODCACHE`, `GOPATH`, `GRADLE_USER_HOME`, `JAVA_HOME`, `GOROOT` and the XDG variables.
